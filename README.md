# Proyek Daftar Riwayat Hidup

## Deskripsi Proyek
Proyek ini merupakan pembuatan website daftar riwayat hidup (CV) menggunakan HTML dan CSS. Website ini berisi informasi mengenai identitas diri, riwayat pendidikan, keterampilan, dan informasi pendukung lainnya.

## Tujuan Proyek
- Mempelajari dasar HTML dan CSS.
- Membuat daftar riwayat hidup dalam bentuk website.
- Menerapkan desain dan tata letak halaman web.
- Mengembangkan keterampilan dasar pemrograman web.

## Teknologi yang Digunakan
- **HTML**: Membuat struktur dan isi website.
- **CSS**: Mengatur desain, warna, ukuran, dan tata letak website.

## Fitur Website
- Informasi identitas diri.
- Riwayat pendidikan.
- Keterampilan.
- Foto profil.
- Tampilan yang sederhana dan menarik.
